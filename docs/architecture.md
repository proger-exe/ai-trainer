# Архитектура системы

## Общее описание

Telegram-бот "Тренажёр коммуникаций" - это система для обучения навыкам коммуникации через интерактивные уроки, тесты и анализ ситуаций. Система интегрирована с сайтом онбординга (example.com) и использует AI для анализа текста.

## Компоненты системы

### 1. Основные компоненты

```

│                      Telegram Bot                            │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐     │
│  │   Handlers   │  │  Keyboards   │  │   Services   │     │
│  └──────────────┘  └──────────────┘  └──────────────┘     │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                      Core Layer                              │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐     │
│  │   Database   │  │  Container   │  │    Bridge    │     │
│  └──────────────┘  └──────────────┘  └──────────────┘     │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                    External Services                         │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐     │
│  │  API Server  │  │  Supabase    │  │  AtlantSDK   │     │

│  └──────────────┘  └──────────────┘  └──────────────┘     │
└─────────────────────────────────────────────────────────────┘
```

### 2. Поток данных

```
Пользователь → Telegram Bot → Handler → Service → Database
                                      ↓
                                   AtlantSDK (AI анализ)
                                      ↓
                                   Response → User
```

### 3. Интеграция с сайтом онбординга

```
Сайт (example.com) → API Server → Database → Bot Notification
                ↓
         Supabase (опционально)
                ↓
         Supabase Poller → Database → Bot Notification
```

## Технологический стек

- **Python 3.11+**
- **aiogram 3.13** - фреймворк для Telegram ботов
- **aiosqlite** - асинхронная работа с SQLite
- **aiohttp** - HTTP сервер для API
- **Google Gemini AI** - анализ текста через AtlantSDK
- **Supabase** - облачная БД для результатов теста (опционально)

## База данных

Используется SQLite с асинхронным доступом через aiosqlite. Основные таблицы:

- `users` - пользователи
- `user_points` - баллы пользователей
- `lessons` - уроки
- `user_lessons` - прогресс по урокам
- `user_quiz_results` - результаты теста онбординга
- `user_quiz_history` - история прохождений теста
- `events` - события для аналитики

## Запуск системы

1. **Telegram Bot** - основной процесс, обрабатывает сообщения
2. **API Server** - HTTP сервер на порту 8080 для приёма данных с сайта
3. **Supabase Poller** - фоновый процесс проверки новых результатов в Supabase

Все компоненты запускаются параллельно в одном процессе через asyncio.

## Конфигурация

Настройки хранятся в `.env` файле:

- `TELEGRAM_BOT_TOKEN` - токен Telegram бота
- `GEMINI_API_TOKEN` - токен Google Gemini API
- `ONBOARDING_WEBAPP_URL` - URL теста на сайте
- `DATABASE_PATH` - путь к файлу БД
- `ADMIN_IDS` - ID администраторов (через запятую)
